# Third-party data

`data/TruthfulQA-2.csv` is the project's 817-question version of TruthfulQA, by Stephanie Lin, Jacob Hilton, and Owain Evans. The [upstream repository](https://github.com/sylinrl/TruthfulQA) is distributed under [Apache License 2.0](https://github.com/sylinrl/TruthfulQA/blob/main/LICENSE); a copy is included as `LICENSES/TruthfulQA-Apache-2.0.txt`.

The local file was supplied with the coursework and is renamed relative to upstream. It has not been substituted with the current upstream CSV, so evaluation uses the references originally supplied to the project. The source column and attribution are preserved. Model-output files also contain benchmark questions and references; the same benchmark attribution applies to those portions. This notice does not assign a new licence to the group project's generated answers or code.

Lin, S., Hilton, J., & Evans, O. (2021). *TruthfulQA: Measuring How Models Mimic Human Falsehoods.* [Paper](https://arxiv.org/abs/2109.07958).
